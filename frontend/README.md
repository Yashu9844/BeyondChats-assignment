# BeyondChats Frontend - React Application

Premium UI for displaying AI-enhanced articles with references.

## Features

- 🎨 **Awwwards-level Design** - Clean, minimal black/white theme
- ✨ **Smooth Animations** - Framer Motion for fluid transitions
- 📱 **Fully Responsive** - Mobile-first design
- 🚀 **Fast Performance** - Built with Vite + React
- 🎯 **Article Display** - Card-based layout with detail views
- 📚 **References Section** - Clickable curated references
- 🔄 **Collapsible Original** - View original article content

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS v4** - Styling
- **Framer Motion** - Animations
- **React Router** - Navigation
- **Axios** - API requests

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

Create `.env.local` file:

```bash
VITE_LARAVEL_API_URL=http://beyondchatsbackend.test/api
```

### 3. Run Development Server

```bash
npm run dev
```

Visit: **http://localhost:5173/**

## Build for Production

```bash
npm run build
```
